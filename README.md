# 세무 투두

세무 업무용 투두리스트입니다. 설치 없이 브라우저에서 바로 쓰는 웹앱(PWA)입니다.

## 기능

### 1. 오늘 할일
- 날짜별 할일 관리 (◀ ▶로 날짜 이동, 날짜 선택)
- 할일마다 **세목**(부가세·원천세·법인세·종소세·지급명세서·4대보험·지방세·기장·상담 등), **거래처**, **알림 시간**, **중요도** 지정
- **반복 할일**: 매일 / 평일 / 매주 / 매월 (예: 매월 5일 급여자료 수령)
- **내일로 미루기**, 지난 날짜의 미완료 할일 **오늘로 가져오기**
- 완료율 표시, 미완료·완료·세목별 필터
- **오늘의 브리핑**: 이 날 마감되는 세무일정과 14일 안에 다가오는 마감을 D-day로 표시

### 2. 월별 세무일정
- 달력에 주요 신고·납부 기한 자동 표시 (원천세, 4대보험, 부가세 예정·확정, 법인세, 종소세, 지급명세서, 지방세, 종부세 등)
- 기한이 **주말·공휴일이면 다음 영업일로 자동 연장**하고 원래 기한도 함께 표시
- 거래처별 일정 직접 추가 (예: 3월 결산법인 법인세 신고)
- 일정 완료 체크, "할일로" 버튼으로 오늘 할일에 추가
- **캘린더(.ics) 내보내기**: 1년치 세무일정을 휴대폰·구글·아웃룩 캘린더에 등록 (D-3, 당일 오전 9시 알림 포함)

### 3. 알람
- **매일 브리핑 알람**: 지정한 시간(기본 09:00)에 오늘 할일 수와 마감 임박 일정(D-7·D-3·D-1·당일 선택)을 알림
- **할일 시간 알림**: 시간을 지정한 할일은 그 시간에 알림
- 브라우저 시스템 알림 + 화면 알림 + 소리

> 알람은 앱(브라우저 탭 또는 홈 화면에 설치한 앱)이 열려 있을 때 울립니다. 알람 시간에 닫혀 있었다면 그날 처음 열 때 브리핑을 보여줍니다.
> 앱을 닫아도 알림을 받으려면 월별 세무일정 화면에서 **캘린더(.ics) 내보내기**로 휴대폰 캘린더에 등록하세요.

## 사용 방법

- 웹 주소: https://kjh6535313-a11y.github.io/tax-code/ (휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 사용)
- 가장 간단한 방법: `index.html`을 브라우저로 열기 (데이터 저장·알람 동작, 오프라인 캐시·설치는 제외)
- 권장: GitHub Pages 등 https 주소에 올리거나 로컬 서버로 실행하면 **홈 화면에 설치**할 수 있고 시스템 알림이 더 안정적으로 동작합니다.
  ```bash
  python3 -m http.server 8000
  # http://localhost:8000 접속
  ```

## 데이터

- 모든 데이터는 사용하는 브라우저의 localStorage에만 저장됩니다 (서버 전송 없음).
- 설정 화면에서 JSON 백업/복원이 가능합니다. 브라우저 데이터를 지우면 사라지므로 주기적으로 백업하세요.

## 주의

- 기본 세무일정은 12월 결산법인·일반적인 경우 기준입니다. 거래처 상황(반기납부, 사업연도, 성실신고확인 대상 등)에 맞게 설정 화면에서 필요 없는 일정을 끄고, 개별 일정을 추가해 쓰세요.
- 세법 개정(예: 근로소득 간이지급명세서 월별 제출 전환)이나 임시공휴일은 반영이 늦을 수 있으니 국세청 공지로 확인하세요. 공휴일은 2026~2027년이 내장되어 있고 설정에서 추가할 수 있습니다.

## 파일 구조

```
index.html            화면
css/style.css         스타일 (라이트/다크 모드)
js/tax-data.js        세무일정 규칙, 공휴일, 기한 연장 계산
js/store.js           데이터 저장 (할일, 반복, 일정, 설정)
js/alarm.js           매일 브리핑·할일 알림
js/app.js             화면 렌더링과 이벤트
sw.js                 오프라인 캐시, 알림 클릭 처리
manifest.webmanifest  홈 화면 설치 정보
```
